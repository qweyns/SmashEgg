# Проверка SmashEgg перед релизом (версия 4.0.0)

## Автоматическая проверка

```sh
./mvnw --batch-mode --no-transfer-progress clean verify
```

Проверить `target/surefire-reports/` и содержимое `target/SmashEgg-4.0.0.jar`:

- `plugin.yml`: версия `4.0.0`, `main: org.karton.smashegg.SmashEgg`, `api-version: '1.21'`;
- структура классов соответствует пакетам: `command/`, `config/`, `effect/`, `listener/`, `text/`, `stats/`, `util/`;
- присутствуют `config.yml` и языковые файлы `lang/*.yml`;
- отсутствуют `org/bukkit/`, `org/junit/`, `org/mockito/` и не перенесённых `net/kyori/`.

## Серверная матрица

Выполнить на тестовых Spigot/Paper 1.21.x (Java 21) и указать точные версии серверов и плагинов защиты в отчёте.

| Сценарий | Ожидаемое поведение |
|---|---|
| Первый запуск без конфига | Создаётся config.yml, команда зарегистрирована, ошибок нет |
| Старый конфиг 2.0/3.0 | Загружается без удаления, новые ключи берутся из defaults, исходный файл не перезаписан |
| Успешный reload | Новые шансы, blacklist, сообщения, звуки и частицы применяются сразу |
| Некорректный YAML / шанс -1 или 101 / неизвестный звук | Reload отклонён, причина в консоли, старые настройки продолжают работать |
| Некорректный конфиг при запуске | Плагин отключён, причина видна в консоли |
| Команда без права reload, с лишними аргументами | Reload не выполняется; корректное сообщение |
| Автодополнение без прав | reload не предлагается |
| Консоль: smashegg reload | MiniMessage читаем, команда работает |
| Survival, обычный блок, шанс 0 | Нет моба, ровно одно яйцо списано, сообщение и звук failure |
| Survival, обычный блок, шанс 100 | Плагин не отменяет действие; стандартный призыв при допустимых условиях |
| Спавнер, поломка 100 | Тип спавнера прежний, одно яйцо списано, эффект egg-break |
| Спавнер, поломка 0 или отключена | Vanilla меняет тип, после подтверждения слышен success |
| Повторное яйцо того же типа в спавнер | Нет ложного звука смены типа |
| Запрещённый моб в спавнер | Тип прежний, яйцо сохранено, denied; также при выключенной поломке |
| Запрещённый моб на обычном блоке | Применяется обычный шанс, blacklist не действует |
| Яйцо во второй руке, основная пуста | Расход только во второй руке |
| Яйца в обеих руках, шанс 0 | После отказа не списываются яйца из обеих рук за один тик |
| Последнее яйцо в слоте | Слот пуст, нет предмета с нулевым количеством |
| Быстрые повторные клики | Нет отрицательных количеств и повторных эффектов после отказа в том же тике |
| Creative, affect-creative=false / true | Соответственно нет случайной поломки / расход как в Survival |
| Creative и bypass с запрещённым мобом | Blacklist по-прежнему запрещает действие |
| Игрок без smashegg.use | Контролируемое действие запрещено без расхода яйца |
| Игрок с smashegg.bypass | Нет случайной поломки; blacklist и use действуют |
| Открытие сундука/двери с яйцом | Нет случайной поломки |
| Приседание + яйцо на интерактивном блоке | Шанс применяется |
| Spectator / левый клик / обычное куриное яйцо | Обработчик не вмешивается |
| Защищённый регион, запрет использования предмета/блока | Нет расхода и сообщений SmashEgg для уже запрещённого события |
| Защита отменяет смену спавнера после SmashEgg | Нет ложного звука success; отдельно проверить порядок слушателей и расход при неудаче |
| Пустой спавнер, если версия поддерживает | Нет NullPointerException при проверке успеха |
| Новые стандартные яйца на целевой версии | Шансы и blacklist работают без добавления Java-таблицы |
| sounds/messages с пустой строкой | Соответствующий эффект отключён |
| Второй игрок рядом | Персональные звуки SmashEgg ему не воспроизводятся |

## Руchecking конфигурации

- [`plugin.yml`] версия 4.0.0, main-класс `org.karton.smashegg.SmashEgg`, api-version `'1.21'`
- [`config.yml]` секции `defaults.sounds`, `defaults.particles`, `sounds`, `messages`, `placeholders` (в lang) существуют и парсятся корректно
- [`lang/en_US.yml`] и [`lang/ru_RU.yml`] парсятся, плейсхолдеры определены
- Каждый ключ, упомянутый в документации, реально существует в коде (command handler, plugin settings, listener)
- `mvnw clean verify` проходит на Java 21 без ошибок
