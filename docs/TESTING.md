# Проверка SmashEgg перед релизом

## Автоматическая проверка

```sh
./mvnw --batch-mode --no-transfer-progress clean verify
```

Проверить `target/surefire-reports/` и содержимое `target/SmashEgg-4.0.0.jar`:

- `plugin.yml`: версия `4.0.0`, `main: org.karton.smashegg.SmashEgg`, `api-version: '1.21'`, `folia-supported: false`, шесть прав;
- присутствуют `config.yml`, `lang/ru_RU.yml`, `lang/en_US.yml`;
- в JAR есть пакеты `org/karton/smashegg/{command,config,effect,listener,text,stats,util}/`;
- отсутствуют `org/bukkit/`, `net/kyori/`, `org/junit/`, `org/mockito/` — библиотек в JAR быть не должно, их предоставляет Paper.

## Серверная матрица

Выполнить на тестовом **Paper 1.21.x** (Java 21+) и, при использовании форка, на целевом Purpur той же ветки. Spigot больше не является целевой платформой. Указать точные версии серверов и плагинов защиты в отчёте. Эта матрица — план проверки, а не заявление, что серверные тесты уже пройдены.

### Загрузка и команды

| Сценарий | Ожидаемое поведение |
|---|---|
| Первый запуск без конфига | Создаются config.yml, lang/ru_RU.yml, lang/en_US.yml; команда зарегистрирована, ошибок нет |
| Старый конфиг 2.x | Загружается без удаления, affect-creative=false, исходный файл не перезаписан |
| Конфиг 2.x/3.x со старыми именами звуков и со `sounds.failure` | Работает, в консоли предупреждение с предложением ключа/нового имени |
| Конфиг 3.x с `messages.<ключ>` строкой | Принимается как `output: chat`, текст прежний |
| Старый `config-version` | Загружается, в консоли предупреждение о схеме |
| Успешный reload | Новые шансы, правила миров/мобов, фильтр, сообщения, звуки и частицы применяются сразу |
| Некорректный YAML / шанс -1 или 101 / неизвестный звуковой ключ / неизвестное имя частиц | Reload отклонён, причина в консоли, старые настройки продолжают работать |
| Неизвестное *поле* в `settings`, `settings.worlds.<мир>`, `sounds.<ключ>`, `defaults`, `files`, `stats` | Загрузка успешна, в консоли предупреждение с именем поля |
| Новый ключ в `sounds` / `particles` / `messages` или в `lang/*.yml` | Загрузка без предупреждения «unknown config key» |
| `defaults.sounds` / `defaults.particles` | Строковые звуки и частицы без своих volume/count/offset берут эти значения |
| `particles.<ключ>.offset-y` | Частицы появляются со смещением, а не всегда на +1 по Y |
| `stats.effects` и `stats.counters` | `/smashegg stats` показывает новые счётчики; эффект пишет в указанный счётчик |
| `placeholders:` в языковом файле | `{hand}` `{mode}` `{spawner}` `{creative}` `{filter}` и «не задано» в `/info` берутся из языка |
| `files.lang-directory` / `files.stats-file` | Язык и статистика читаются из указанных относительных путей; `../` отклоняется |
| Неверное имя моба в `settings.entities` | Загрузка успешна, в консоли предупреждение с нормализованным именем |
| Звук/частицы из датапака (`my_pack:custom_sound`, имя частицы из датапака) | Работают, если существуют на сервере |
| Некорректный конфиг при запуске | Плагин отключён, причина видна в консоли |
| `settings.language: en_US` | Сообщения на английском; несуществующий код — откат на встроенный русский с предупреждением |
| Правка `lang/ru_RU.yml` на сервере + reload | Изменённые тексты применяются без перезапуска |
| Команда без нужного права, с лишними аргументами | Действие не выполняется; корректное сообщение |
| Автодополнение без прав | Недоступные подкоманды не предлагаются |
| Консоль: `smashegg reload` / `info` / `stats` | MiniMessage читаем, все три команды работают; в `info` мир показан как `-` |
| `/smashegg`, `/smashegg info`, `info world_nether`, `info ENDER_DRAGON`, `info world_nether ENDER_DRAGON` | Показаны версия, соответствующие правила, фильтр, cooldown; `{entity}`/`{world}` подставлены |
| `/smashegg stats` после использования яиц | Счётчики совпадают с фактическими действиями; `{used}`, `{broken}`, `{failed}`, `{denied}`, `{succeeded}` заполнены |
| `/smashegg stats reset` | Счётчики обнулены, `stats.yml` перезаписан сразу; право `stats.reset` обязательно |

### Механика яиц

| Сценарий | Ожидаемое поведение |
|---|---|
| Survival, обычный блок, шанс 0 | Нет моба, ровно одно яйцо списано, эффект `ground-failure` (сообщение, звук, частицы) |
| Survival, обычный блок, шанс 100 | Плагин не отменяет действие; стандартный призыв при допустимых условиях; эффект `success` |
| `failure-action: drop` / `keep`, шанс 0 | Яйцо выброшено под ноги / яйцо сохранено; действие отменено в обоих случаях |
| Спавнер, поломка 100 | Тип спавнера прежний, одно яйцо списано, эффект `egg-break` |
| Спавнер, поломка 0 или отключена | Vanilla меняет тип, после подтверждения срабатывает `success` |
| Повторное яйцо того же типа в спавнер | Нет ложного эффекта смены типа |
| Запрещённый моб в спавнер (BLACKLIST) | Тип прежний, яйцо сохранено, `denied`; также при выключенной поломке |
| `entity-filter: whitelist`, моб вне `allowed-entities` | `denied`, яйцо сохранено |
| `entity-filter: whitelist` и только `black-entities` | Работает как белый список из `black-entities` (совместимость) |
| Запрещённый моб на обычном блоке | Применяется обычный шанс, фильтр не действует |
| `settings.worlds.<мир>` с другим шансом | В этом мире действует переопределение, в других — глобальное |
| `settings.entities.<моб>` с `egg-break-on-spawner: false` | Для этого моба поломки нет, для остальных есть |
| Мир + моб одновременно | Действует правило мира с мобом, а не по отдельности |
| Мир в `disabled-worlds` | Яйца работают как в ванили, права не проверяются, статистика не растёт |
| `cooldown-ticks: 0` / большое значение | Блокировка после неудачи соответственно отсутствует / длится заявленное время |
| Яйцо во второй руке, основная пуста | Расход только во второй руке; `{hand}` = слово из `placeholders.hand.off` |
| Яйца в обеих руках, шанс 0 | После отказа не списываются яйца из обеих рук за один тик |
| Последнее яйцо в слоте | Слот пуст, нет предмета с нулевым количеством |
| Быстрые повторные клики | Нет отрицательных количеств и повторных эффектов в пределах cooldown |
| Creative, affect-creative=false / true | Соответственно нет случайной поломки / расход как в Survival |
| Creative и bypass с запрещённым мобом | Фильтр по-прежнему запрещает действие |
| Игрок без smashegg.use | Контролируемое действие запрещено без расхода яйца |
| Игрок с smashegg.bypass | Нет случайной поломки; фильтр и use действуют |
| Открытие сундука/двери с яйцом | Нет случайной поломки |
| Приседание + яйцо на интерактивном блоке | Шанс применяется |
| Spectator / левый клик / обычное куриное яйцо | Обработчик не вмешивается |
| Защищённый регион, запрет использования предмета/блока | Нет расхода и сообщений SmashEgg для уже запрещённого события |
| Защита отменяет смену спавнера после SmashEgg | Нет ложного эффекта `success`; отдельно проверить порядок слушателей и расход при неудаче |
| Пустой спавнер, если версия поддерживает | Нет NullPointerException при проверке успеха |
| Новые стандартные яйца на целевой версии | Шансы и фильтр работают без добавления Java-таблицы |

### Эффекты и вывод

| Сценарий | Ожидаемое поведение |
|---|---|
| `output: actionbar` / `title` / `none` | Сообщение в action bar / титлом / не выводится; звук и частицы при этом работают |
| Плейсхолдеры `{player} {world} {entity} {chance} {hand} {mode}` | Подставлены фактические значения, неизвестный плейсхолдер остаётся как есть |
| Цвета и градиенты MiniMessage | HEX и `<gradient>` отображаются в клиенте без Adventure-мостов |
| Текст сообщения с литеральными `<...>` из имени игрока/мира | Отображается как текст, не разбирается как тег |
| `sounds.<ключ>` с `volume`, `pitch`, `source` | Звук слышен с заданной громкостью и высотой; `source: music` уходит в соответствующий канал клиента |
| `particles.<ключ>` с `count`, `spread`, `speed`, `offset-y` | Частицы видны со смещением в заявленном объёме |
| Пустая строка в `sounds`/`particles`/`messages` | Соответствующий эффект отключён |
| `log-events: true` | В консоли по строке на сработавший эффект; при `false` — тишина |
| Второй игрок рядом | Персональные эффекты SmashEgg ему не воспроизводятся |
| Остановка сервера, затем запуск | `stats.yml` сохранён и прочитан, счётчики не обнулились |

Отдельно подтвердить документированные границы: клик по существу, раздатчики, воздух/вода без выбранного блока и кастомные яйца с изменённым типом не расширяют гарантии плагина.
