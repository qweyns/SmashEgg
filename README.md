# SmashEgg 🥚 — 3.0.0

Серверный плагин для **Paper**: настраиваемая вероятность поломки яиц призыва при использовании на блоках и запрет определённых мобов в спавнерах.

## Возможности

- Отдельные шансы для спавнеров и обычного использования на блоках.
- Чёрный список спавнеров: запрещённое яйцо не расходуется.
- Поддержка основной и второй руки; при поломке списывается ровно один предмет из соответствующего слота.
- Creative по умолчанию не участвует в случайной поломке. Это можно изменить в конфиге.
- Отдельное право обхода случайной поломки, не обходящее чёрный список.
- MiniMessage, HEX и градиенты; возможность отключать сообщения и звуки пустой строкой.
- Проверка настроек и безопасная перезагрузка: неверный конфиг не заменяет рабочий.
- Распознавание яиц по материалам работающего сервера, без ручного перечня мобов.
- Звуки задаются namespaced-ключами, поэтому работают и звуки из датапаков и чужих плагинов.

## Требования и совместимость

- **Сервер: Paper 1.21 и новее** (включая форки на его основе — Purpur и подобные). **Spigot и CraftBukkit больше не поддерживаются**: плагин собирается против Paper API и использует Adventure напрямую из сервера.
- **Java 21 или новее** — и для сборки, и для сервера (Paper 1.21.x не запускается на Java 17).
- Базовый API сборки — **Paper API 1.21.11**, `api-version: '1.21'`.
- Folia не поддерживается: используется обычный Bukkit scheduler (`folia-supported: false` в `plugin.yml`).

Версию Paper, под которую собирается плагин, задаёт свойство `paper.api.version` в [pom.xml](pom.xml). При сборке под другую ветку держите его согласованным с `api-version` в [plugin.yml](src/main/resources/plugin.yml).

## Установка и обновление

1. Соберите JAR или скачайте артефакт **успешной** сборки GitHub Actions.
2. Остановите сервер. Удалите прежний JAR SmashEgg из `plugins`, если он есть.
3. Поместите `SmashEgg-3.0.0.jar` в `plugins` и запустите сервер.
4. Настройте `plugins/SmashEgg/config.yml` и выполните `/smashegg reload`.

**Старый конфиг удалять не нужно.** Ключи 2.x сохранены, отсутствующие настройки берутся из встроенных значений без перезаписи файла.

### Переход с 2.x

| Что изменилось | Действие |
|---|---|
| Только Paper | Обновите сервер до Paper/Purpur 1.21+ и Java 21+ |
| Звуки — namespaced-ключи: `entity.player.levelup` вместо `ENTITY_PLAYER_LEVELUP` | Ничего делать не нужно для четырёх стандартных значений: старые имена принимаются, в консоль пишется предупреждение. Любое другое старое имя нужно заменить ключом |
| `adventure-platform-bukkit` больше не используется | Ничего: Adventure предоставляет сам Paper, в JAR библиотек нет |
| Версия JAR `3.0.0` | Замените файл в `plugins` |

## Как работают правила

### Спавнер

1. Проверяется `smashegg.use`.
2. Проверяется `black-entities`. При запрете действие отменяется **без расхода яйца**.
3. Для игроков без исключения проверяется вероятность поломки, если `egg-break-on-spawner: true`.
4. При неудаче расходуется одно яйцо, действие отменяется.
5. При удаче изменение спавнера выполняет Minecraft, а не плагин. Звук `success` воспроизводится на следующем тике только после подтверждённой смены типа моба на ожидаемый. Повторное применение того же типа не сопровождается этим звуком.

### Обычное использование на блоке

`ground-spawn-chance` — вероятность **пройти проверку плагина**, а не гарантия появления моба. При неудаче действие отменяется и расходуется одно яйцо. При удаче применяется стандартная механика Minecraft; другие плагины, коллизии и правила мира всё ещё могут помешать призыву.

- `ground-spawn-chance: 0` — проверка всегда неудачна; `100` — всегда успешна.
- `egg-break-chance: 0` — поломки на спавнере нет; `100` — всегда есть, если она включена и игрок не освобождён от неё.
- Обычный клик по интерактивному блоку (сундук, дверь и т. п.) пропускается, чтобы не ломать яйцо при открытии. Для применения проверки при использовании яйца на таком блоке нужно присесть.
- Отказ/поломка блокирует повторную обработку яиц этого игрока до следующего тика, включая вторую руку.
- Spectator не обрабатывается. Creative освобождён от шанса по умолчанию, но **не от прав и чёрного списка**. При `affect-creative: true` неудача расходует яйцо и в Creative.
- Чёрный список относится **только к спавнерам**, не к обычному призыву.

### Границы обработки

Плагин работает с правым кликом яйцом по блоку (`PlayerInteractEvent`). Клик непосредственно по существу, использование в воздухе/воде без выбранного блока, раздатчики и призыв командами не входят в эту механику. Это не глобальная система запрета появления мобов.

Интерактивность определяется `Material.isInteractable()`. Эта классификация консервативна и на некоторых версиях включает блоки без действия при конкретном клике. Такие обычные клики тоже пропускаются; используйте приседание для проверки.

Учитываются уже отменённые события и отдельные запреты использования блока/предмета. Совместимость с конкретными плагинами защиты нужно проверять: более поздний обработчик может отменить событие после решения SmashEgg. Успешный обычный призыв не отслеживается постфактум.

Тип яйца определяется его материалом. Кастомные яйца с изменённым через компоненты типом сущности отдельно не разбираются: при использовании таких предметов правила материалов не являются надёжным ограничением фактического типа моба.

## Команда и права

| Команда / право | Поведение | По умолчанию |
|---|---|---|
| `/smashegg reload` | Перечитать и проверить конфиг; нужны `smashegg.use` и `smashegg.reload` | — |
| `smashegg.use` | Доступ к команде и использованию яиц в обрабатываемых плагином кликах; без права действие запрещается, яйцо сохраняется | Все |
| `smashegg.reload` | Перезагрузка настроек | Операторы |
| `smashegg.bypass` | Пропустить только случайную поломку; право `use` и чёрный список по-прежнему проверяются | Никто, включая операторов |

Автодополнение `reload` доступно только с нужными правами. Команда работает и из консоли. Лишние аргументы отклоняются.

## Конфигурация

Краткий пример (все звуки и сообщения — в [config.yml](src/main/resources/config.yml)):

```yaml
settings:
  egg-break-on-spawner: true
  egg-break-chance: 30
  ground-spawn-chance: 70
  affect-creative: false
  black-entities:
    - ENDER_DRAGON
    - WITHER
    - WARDEN

sounds:
  success: entity.player.levelup
  failure: entity.villager.no
  denied: block.anvil.land
  egg-break: block.glass.break
```

**Звуки.** Значение — namespaced-ключ Minecraft: `entity.player.levelup`, `minecraft:entity.player.levelup` или свой `my_pack:custom_sound`. Пустая строка `""` отключает звук, неизвестное имя отклоняет загрузку конфига. Имена из Bukkit 1.x (`ENTITY_PLAYER_LEVELUP`, `ENTITY_VILLAGER_NO`, `BLOCK_ANVIL_LAND`, `BLOCK_GLASS_BREAK`) принимаются для совместимости с конфигом 2.x и сопровождаются предупреждением в консоли — остальные значения нужно писать ключами.

**Мобы.** Названия нечувствительны к регистру; поддерживаются старые имена `MUSHROOM_COW` → `MOOSHROOM` и `SNOWMAN` → `SNOW_GOLEM`. Имя моба без соответствующего яйца на текущем сервере сохраняется с предупреждением: это позволяет переносить конфиг между версиями, но требует внимания к опечаткам.

Пустые `sounds.<ключ>: ""` / `messages.<ключ>: ""` отключают соответствующий эффект. Звуки слышит только действующий игрок. Игровые сообщения настраиваются; технические диагностические сообщения консоли остаются в коде.

## Сборка и тесты

Maven Wrapper закрепляет Maven 3.9.9; вручную устанавливать Maven не требуется. При первом запуске нужны доступ к Maven Central и репозиторию PaperMC. JDK 21+ необходимо установить отдельно.

```bash
# Linux / macOS
./mvnw --batch-mode clean verify

# Windows
mvnw.cmd --batch-mode clean verify
```

Результат: `target/SmashEgg-3.0.0.jar`. Shade-плагин не используется: серверный API и Adventure предоставляет Paper, в JAR плагина библиотек нет.

JUnit / Mockito тесты проверяют шансы и границы, права, blacklist, Creative, обе руки, расход последнего яйца, отменённые события, интерактивные блоки, подтверждение смены спавнера, разбор звуковых ключей, валидацию и атомарность reload. GitHub Actions выполняет `clean verify` на Java 21 и 25 и публикует JAR и отчёты тестов.

Unit-тесты не заменяют запуск Minecraft. Перед установкой на рабочий сервер выполните [ручной чек-лист](docs/TESTING.md), особенно с плагинами защиты регионов.

## Структура

- `SmashEgg` — жизненный цикл, атомарная загрузка настроек и отправка эффектов через Adventure.
- `EggListener` — игровые события и работа с инвентарём.
- `PluginSettings` — неизменяемый проверенный снимок конфигурации.
- `EggTypes` — распознавание материалов яиц и нормализация названий.
- `Sounds` — разбор звуковых ключей и совместимость со старыми именами Bukkit.
- `CommandHandler` — команда и автодополнение.
- `ColorUtil` — MiniMessage.

Что пока не реализовано и какие есть идеи развития — в [docs/ROADMAP.md](docs/ROADMAP.md).
