# Что не хватает SmashEgg

Снимок по состоянию на 4.0.0. Раздел «Закрыто» перечисляет то, что было в списке для 3.0.0 и сделано; остальное — актуальные ограничения. Ссылки указывают на место в коде, где ограничение живёт.

## 1. Заметно пользователю

| # | Чего нет | Где упирается | Что дало бы |
|---|---|---|---|
| 1 | **Проверка звукового ключа по реестру сервера.** Ключ проверяется синтаксически; опечатка даёт тишину | `Sounds.parse()` | На сервере сверять с `Registry.SOUNDS` и предупреждать, что звук не существует (как сделано для частиц в `Particles.resolve`) |
| 2 | **Звук слышит только действующий игрок.** Нельзя сделать «стекло разбилось» для окружающих | `SmashEgg.effect()` | `sounds.<ключ>.audience: self \| nearby \| world` + радиус |
| 3 | **PlaceholderAPI.** Свои плейсхолдеры есть, внешних нет | `Placeholders.java` | `{papi_...}` для интеграции с Vault/другими плагинами (soft-depend) |
| 4 | **bStats.** Счётчики свои, в общий рейтинг плагин не попадает | `Stats.java` | Графики на bStats.org; обычно делается вместе с релизом |
| 5 | **Субтитры и `showTitle` с таймингами.** `title` отправляется без fade-in/stay/fade-out и без подзаголовка | `SmashEgg.send()` | `messages.<ключ>.times: [10, 40, 10]`, `subtitle` |
| 6 | **Топ игроков в статистике.** Счётчики глобальные, разбивки по игрокам нет | `Stats.java` | `/smashegg stats top`, но это уже хранение PII — нужно делать опциональным |

## 2. Ограничения механики (задокументированы, но не закрыты)

- **Кастомные яйца.** Тип берётся из материала (`EggTypes`), поэтому яйцо с изменённым компонентом `entity_type` обходит фильтр. На Paper это читается через компоненты предмета — можно сделать надёжную проверку.
- **Только клик по блоку.** `PlayerInteractEntityEvent`, раздатчики, призыв командами и использование без выбранного блока не обрабатываются (`EggListener.onPlayerUseEgg`). Для настоящего запрета мобов нужен отдельный слушатель `CreatureSpawnEvent`.
- **Нет «мягкого» запрета мобов вне спавнеров.** Фильтр применяется только к смене типа спавнера; обычный призыв моба не ограничивается ничем, кроме шанса.
- **Folia не поддерживается** — используется обычный Bukkit scheduler (`SmashEgg.onEnable`, `EggListener.confirmSpawnerChange`). Нужен `RegionScheduler`/`EntityScheduler`.

## 3. Технический долг

- **`event.setCancelled(true)` устарел с 1.14** (`EggListener.java:48,90`). Paper предлагает `setUseItemInHand(Result.DENY)` + `setUseInteractedBlock(Result.DENY)`; поведение эквивалентно, но предупреждения компилятора уйдут.
- **`isInteractable()` слишком широкий** (`EggListener.java:58`): часть блоков без действия на клик тоже считается интерактивной, и проверка пропускается без приседания.
- **Нет `paper-plugin.yml`.** Для Paper-only проекта можно включить изоляцию классов загрузчика и убрать зависимость от `plugin.yml`.
- **`onEnable`, регистрация команды и слушателя не покрыты тестами.** Все тесты — юнитные на Mockito; интеграционных (MockBukkit) нет.
- **Нет релизного пайплайна.** CI собирает и тестирует, но не создаёт GitHub Release и не публикует на Hangar/Modrinth.
- **Нет issue/PR-шаблонов, checkstyle/spotbugs, `.editorconfig`.**
- **Статистика пишется только при остановке и при reset** (`SmashEgg.onDisable`, `CommandHandler`): после `kill -9` счётчики теряются с последнего сохранения.

## 4. Организационное

- **Нет описания для площадок** (Hangar/Modrinth/SpigotMC): страницы, скриншоты, список команд для публикации.

## 5. Закрыто в 4.0.0

Из списка для 3.0.0:

- **Per-mob и per-world настройки** — `settings.worlds.<мир>` и `settings.entities.<моб>` с приоритетом «мир + моб → мир → моб → глобальные» (`PluginSettings.rulesFor`).
- **Whitelist-режим** — `settings.entity-filter: WHITELIST` + `settings.allowed-entities` (`FilterMode`).
- **Плейсхолдеры в сообщениях** — `{player}`, `{world}`, `{entity}`, `{chance}`, `{hand}`, `{mode}` и набор для `/info` и `/stats` (`Placeholders`).
- **Не только чат** — `messages.<ключ>.output: chat | actionbar | title | none`.
- **Настройки звука** — `volume`, `pitch`, `source` (`Sounds.parse`, `SmashEgg.effect`).
- **Частицы при поломке** — `particles.<ключ>` с `name/count/spread/speed`, разрешение имени через реестр сервера (`Particles`).
- **`/smashegg info [мир [моб]]`** — эффективные правила, фильтр, версия, путь к конфигу.
- **Статистика** — `stats.yml`, `/smashegg stats`, `/smashegg stats reset` (`Stats`).
- **Локализация** — `lang/ru_RU.yml`, `lang/en_US.yml`, `settings.language`, резерв на встроенный русский текст.

Из раздела «ограничения механики»:

- **Кулдаун** — `settings.cooldown-ticks` вместо жёстко зашитой блокировки на один тик.
- **Не расходовать яйцо при неудаче** — `settings.failure-action: consume | keep | drop`.

Из раздела «технический долг»:

- **Файл `LICENSE`** — проект распространяется по MIT; в `pom.xml` добавлены блоки `licenses`, `scm`, `name`, `url` и `description`.

Из раздела «технический долг»:

- **Неизвестные ключи конфига больше не молчат** — предупреждение в консоль на неизвестное поле и на опечатку (`SectionFields`, `ConfigNodes`); есть `config-version` с предупреждением о старой схеме.

## Предлагаемый порядок работ

1. Страницы на Hangar/Modrinth (лицензия уже есть).
2. Валидация звуковых ключей по `Registry.SOUNDS` и `audience: nearby` (закрывает пункты 1–2 таблицы).
3. Компоненты предмета для кастомных яиц + `CreatureSpawnEvent` как отдельный режим запрета.
4. Folia-поддержка через region scheduler.
5. bStats + релизный пайплайн (GitHub Release, автопубликация).
6. Интеграционные тесты на MockBukkit, checkstyle/`.editorconfig`.
