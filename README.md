# SmashEgg 🥚 — 4.0.0

Серверный плагин для **Paper**: настраиваемая вероятность поломки яиц призыва, правила по мирам и мобам, звуки, частицы, сообщения в чат/action bar/титл и статистика использования.

## Возможности

- Отдельные шансы для спавнеров и обычного использования на блоках.
- **Правила по мирам и по мобам**: переопределение шансов, включение/выключение поломки на спавнере и Creative для отдельного мира или моба.
- **Чёрный или белый список** мобов для спавнеров (`entity-filter: BLACKLIST | WHITELIST`); запрещённое яйцо не расходуется.
- **Плейсхолдеры** в сообщениях: `{player}`, `{world}`, `{entity}`, `{chance}`, `{hand}`, `{mode}`, а в `/info` и `/stats` — `{version}`, `{spawner}`, `{break}`, `{ground}`, `{creative}`, `{filter}`, `{cooldown}`, `{used}`, `{broken}`, `{failed}`, `{denied}`, `{succeeded}`.
- **Куда писать сообщение**: `chat`, `actionbar`, `title` или `none` — на каждое сообщение отдельно.
- **Звуки** с громкостью, высотой тона и источником (`master`, `music`, `record`, `weather`, `block`, `hostile`, `neutral`, `player`, `ambient`, `voice`).
- **Частицы** на поломке яйца и неудаче на земле: имя, количество, разброс, скорость.
- **Статистика** в `stats.yml`: сколько яиц использовано, сломано, отклонено, сколько неудач и удачных призывов, с разбивкой по эффектам; `/smashegg stats` и сброс.
- **Локализация**: `lang/ru_RU.yml` и `lang/en_US.yml`, переключение через `settings.language`; сообщения можно править без правки `config.yml`.
- Creative по умолчанию не участвует в случайной поломке; есть отдельное право обхода.
- Отдельное право обхода случайной поломки, не обходящее фильтр мобов.
- MiniMessage, HEX и градиенты; пустая строка отключает сообщение, звук или частицы.
- Проверка настроек и безопасная перезагрузка: неверный конфиг не заменяет рабочий.
- Распознавание яиц по материалам работающего сервера, без ручного перечня мобов.
- Опциональный журнал событий в консоль (`log-events: true`).

## Требования и совместимость

- **Сервер: Paper 1.21 и новее** (включая форки на его основе — Purpur и подобные). **Spigot и CraftBukkit не поддерживаются**: плагин собирается против Paper API и использует Adventure напрямую из сервера.
- **Java 21 или новее** — и для сборки, и для сервера (Paper 1.21.x не запускается на Java 17).
- Базовый API сборки — **Paper API 1.21.11**, `api-version: '1.21'`, Adventure **4.17.0** (встроен в Paper 1.21).
- **Folia не поддерживается**: используется обычный Bukkit scheduler (`folia-supported: false` в `plugin.yml`). На Folia-сервере плагин не включается.
- Зависимость от внешних плагинов отсутствует: ни PlaceholderAPI, ни Vault не требуются.

Версию Paper, под которую собирается плагин, задаёт свойство `paper.api.version` в [pom.xml](pom.xml). При сборке под другую ветку держите его согласованным с `api-version` в [plugin.yml](src/main/resources/plugin.yml).

## Установка и обновление

1. Соберите JAR или скачайте артефакт **успешной** сборки GitHub Actions.
2. Остановите сервер. Удалите прежний JAR SmashEgg из `plugins`, если он есть.
3. Поместите `SmashEgg-4.0.0.jar` в `plugins` и запустите сервер.
4. Настройте `plugins/SmashEgg/config.yml`, при желании язык в `plugins/SmashEgg/lang/<код>.yml`, и выполните `/smashegg reload`.

**Старый конфиг удалять не нужно.** Ключи 2.x/3.x сохранены, отсутствующие настройки берутся из встроенных значений без перезаписи файла.

### Переход с 3.x

| Что изменилось | Действие |
|---|---|
| Звук `sounds.failure` переименован в `sounds.ground-failure` | Ничего: старое имя продолжает работать, в консоль пишется предупреждение |
| `messages.<ключ>` теперь секция `text` + `enabled` + `output` | Ничего: строка вида `messages.success: "<green>..."` по-прежнему принимается и читается как `output: chat` |
| Появились `settings.worlds`, `settings.entities`, `settings.entity-filter`, `settings.log-events`, `settings.cooldown-ticks`, `particles` | Ничего: значения по умолчанию повторяют поведение 3.x |
| Новые права `smashegg.info`, `smashegg.stats`, `smashegg.stats.reset` | При необходимости выдайте их игрокам |
| Версия JAR `4.0.0` | Замените файл в `plugins` |

### Переход с 2.x

| Что изменилось | Действие |
|---|---|
| Только Paper | Обновите сервер до Paper/Purpur 1.21+ и Java 21+ |
| Звуки — namespaced-ключи: `entity.player.levelup` вместо `ENTITY_PLAYER_LEVELUP` | Ничего для четырёх стандартных значений: старые имена принимаются с предупреждением в консоли. Любое другое старое имя нужно заменить ключом |
| `adventure-platform-bukkit` не используется | Ничего: Adventure предоставляет сам Paper, в JAR библиотек нет |

## Команды и права

Команда `/smashegg` (алиас `/segg`). Все подкоманды работают и из консоли.

| Команда | Что делает | Требуемое право | По умолчанию |
|---|---|---|---|
| `/smashegg` | Список подкоманд | `smashegg.use` | Все |
| `/smashegg reload` | Перечитать и проверить конфиг и язык | `smashegg.reload` | Операторы |
| `/smashegg info [мир\|моб [моб]]` | Эффективные правила: глобальные, для мира, для моба или для мира и моба | `smashegg.info` | Операторы |
| `/smashegg stats` | Статистика из `stats.yml` | `smashegg.stats` | Операторы |
| `/smashegg stats reset` | Обнулить статистику | `smashegg.stats.reset` | Операторы |

| Право | Поведение | По умолчанию |
|---|---|---|
| `smashegg.use` | Доступ к команде и использованию яиц в обрабатываемых кликах; без права действие запрещается, яйцо сохраняется | Все |
| `smashegg.reload` | Перезагрузка настроек | Операторы |
| `smashegg.info` | `/smashegg` и `/smashegg info` | Операторы |
| `smashegg.stats` | `/smashegg stats` | Операторы |
| `smashegg.stats.reset` | `/smashegg stats reset` | Операторы |
| `smashegg.bypass` | Пропустить только случайную поломку; `use` и фильтр мобов по-прежнему проверяются | Никто, включая операторов |

Автодополнение показывает только те подкоманды, на которые есть право, и имена загруженных миров для `info`. Лишние аргументы отклоняются.

Аргументы `/smashegg info` разбираются так: два аргумента — это всегда мир и моб; один аргумент считается миром, если мир с таким именем загружен, и мобом в противном случае; без аргументов берутся правила мира отправителя. Незаданный мир или моб показывается как `-`.

## Как работают правила

### Спавнер

1. Проверяется `smashegg.use`.
2. Проверяется фильтр мобов (`black-entities` или `allowed-entities` в зависимости от `entity-filter`). При запрете действие отменяется **без расхода яйца**.
3. Для игроков без исключения проверяется вероятность поломки, если поломка включена для этого мира/моба.
4. При неудаче расходуется одно яйцо, действие отменяется.
5. При удаче изменение спавнера выполняет Minecraft, а не плагин. Эффект `success` воспроизводится на следующем тике только после подтверждённой смены типа моба на ожидаемый. Повторное применение того же типа не сопровождается этим эффектом.

### Обычное использование на блоке

`ground-spawn-chance` — вероятность **пройти проверку плагина**, а не гарантия появления моба. При неудаче действие отменяется и расходуется одно яйцо. При удаче применяется стандартная механика Minecraft; другие плагины, коллизии и правила мира всё ещё могут помешать призыву.

- `ground-spawn-chance: 0` — проверка всегда неудачна; `100` — всегда успешна.
- `egg-break-chance: 0` — поломки на спавнере нет; `100` — всегда есть, если она включена и игрок не освобождён от неё.
- Обычный клик по интерактивному блоку (сундук, дверь и т. п.) пропускается, чтобы не ломать яйцо при открытии. Для применения проверки при использовании яйца на таком блоке нужно присесть.
- Отказ/поломка блокирует повторную обработку яиц этого игрока до следующего тика, включая вторую руку (`settings.cooldown-ticks: 0` отключает эту блокировку).
- Spectator не обрабатывается. Creative освобождён от шанса по умолчанию, но **не от прав и фильтра**. При `affect-creative: true` неудача расходует яйцо и в Creative.
- Фильтр мобов относится **только к спавнерам**, не к обычному призыву.

### Приоритет правил

Настройки читаются в порядке: **мир + моб → мир → моб → глобальные**. Более конкретное правило перекрывает менее конкретное по каждой настройке отдельно, поэтому можно задать, например, глобальный шанс 30, для мира `world_nether` — 80, а для моба `ENDER_DRAGON` — поломку выключенной.

`disabled-worlds` отключает обработку мира целиком: яйцо работает как в ванили, права не проверяются, статистика не пишется.

### Границы обработки

Плагин работает с правым кликом яйцом по блоку (`PlayerInteractEvent`). Клик непосредственно по существу, использование в воздухе/воде без выбранного блока, раздатчики и призыв командами не входят в эту механику. Это не глобальная система запрета появления мобов.

Интерактивность определяется `Material.isInteractable()`. Эта классификация консервативна и на некоторых версиях включает блоки без действия при конкретном клике. Такие обычные клики тоже пропускаются; используйте приседание для проверки.

Учитываются уже отменённые события и отдельные запреты использования блока/предмета. Совместимость с конкретными плагинами защиты нужно проверять: более поздний обработчик может отменить событие после решения SmashEgg. Успешный обычный призыв не отслеживается постфактум.

Тип яйца определяется его материалом. Кастомные яйца с изменённым через компоненты типом сущности отдельно не разбираются.

## Конфигурация

Все настройки — в [config.yml](src/main/resources/config.yml). Краткий пример:

```yaml
settings:
  language: ru_RU
  cooldown-ticks: 1
  egg-break-on-spawner: true
  egg-break-chance: 30
  ground-spawn-chance: 70
  affect-creative: false
  failure-action: CONSUME
  log-events: false
  entity-filter: BLACKLIST
  black-entities:
    - ENDER_DRAGON
    - WITHER
  worlds:
    world_nether:
      egg-break-chance: 80
  entities:
    ENDER_DRAGON:
      egg-break-on-spawner: false

sounds:
  egg-break:
    key: block.glass.break
    volume: 1.0
    pitch: 1.2
    source: master

particles:
  egg-break:
    name: item_slime
    count: 12

messages:
  egg-break:
    text: "<red>Яйцо разбилось! <dark gray>(шанс <yellow>{chance}%<dark gray>, рука {hand})"
    enabled: true
    output: actionbar
```

**Правила по мирам и мобам.** Ключи `settings.worlds` и `settings.entities` — имена мира и моба. Допустимые поля: `egg-break-on-spawner`, `egg-break-chance`, `ground-spawn-chance`, `affect-creative`. Неизвестное поле или имя моба без яйца на сервере — предупреждение в консоль; неизвестное поле не останавливает загрузку.

**Фильтр мобов.** `entity-filter: blacklist` — запрещены мобы из `black-entities`; `whitelist` — разрешены только мобы из `allowed-entities`, остальные запрещены. В режиме `whitelist` ключ `allowed-entities` имеет приоритет, а при его отсутствии используется `black-entities` (для конфигов, созданных до появления второго имени). Пустой белый список запрещает всех. Регистр значения не важен.

**Что происходит при неудаче.** `failure-action: consume` (по умолчанию) расходует одно яйцо, `drop` — расходует и выбрасывает его под ноги, `keep` — оставляет яйцо в руке (действие всё равно отменяется). Регистр значения не важен.

**Звуки.** Значение — строка-ключ (`entity.player.levelup`, `minecraft:entity.player.levelup`, `my_pack:custom_sound`) или секция с `key`, `volume` (0–10), `pitch` (0–2) и `source`. Пустая строка `""` отключает звук, неизвестное имя отклоняет загрузку конфига. Имена из Bukkit 1.x (`ENTITY_PLAYER_LEVELUP`, `ENTITY_VILLAGER_NO`, `BLOCK_ANVIL_LAND`, `BLOCK_GLASS_BREAK`) принимаются для совместимости с конфигом 2.x и сопровождаются предупреждением.

**Частицы.** Значение — строка-имя (`item_slime`) или секция с `name`, `count` (1–1000), `spread` (0–8) и `speed` (0–10). Имя ищется через реестр частиц сервера, поэтому частицы из датапаков тоже работают; неизвестное имя отклоняет загрузку конфига.

**Сообщения.** Каждое сообщение — секция с `text` (MiniMessage + плейсхолдеры), `enabled` и `output` (`chat`, `actionbar`, `title`, `none`). Строковая форма `messages.success: "<green>..."` по-прежнему принимается.

| Плейсхолдер | Где работает | Значение |
|---|---|---|
| `{player}` | игровые сообщения | имя игрока |
| `{world}` | игровые сообщения и `/info` | мир игрока; `-`, если отправитель — консоль без аргумента |
| `{entity}` | игровые сообщения и `/info` | нормализованное имя моба, например `ENDER_DRAGON` |
| `{chance}` | игровые сообщения | шанс, который проверялся: для спавнера — поломки, иначе — прохождения |
| `{hand}` | игровые сообщения | `main` или `off` |
| `{mode}` | игровые сообщения | `spawner` или `ground` |
| `{version}` | `/info` | версия плагина |
| `{spawner}` | `/info` | `on` или `off` — включена ли поломка на спавнере |
| `{break}`, `{ground}` | `/info` | шансы в процентах |
| `{creative}` | `/info` | `yes` или `no` — учитывается ли Creative |
| `{filter}` | `/info` | `blacklist` или `whitelist` |
| `{cooldown}` | `/info` | `settings.cooldown-ticks` |
| `{used}`, `{broken}`, `{failed}`, `{denied}`, `{succeeded}` | `/stats` | счётчики из `stats.yml` |

Неизвестный плейсхолдер остаётся в тексте как есть, поэтому опечатка видна сразу, а не превращается в пустое место. Значения подставляются с экранированием MiniMessage: имя игрока или мира с `<...>` отобразится текстом.

**Мобы.** Названия нечувствительны к регистру; поддерживаются старые имена `MUSHROOM_COW` → `MOOSHROOM` и `SNOWMAN` → `SNOW_GOLEM`.

**Локализация.** Тексты берутся из `plugins/SmashEgg/lang/<settings.language>.yml`; при отсутствии файла или ключа используется встроенный русский текст. Файлы `ru_RU.yml` и `en_US.yml` поставляются с плагином и копируются при первом запуске.

**Статистика.** Счётчики хранятся в `plugins/SmashEgg/stats.yml` и записываются при остановке сервера и сразу после `/smashegg stats reset`. Файл можно править и удалять вручную — плагин начнёт с нуля.

## Сборка и тесты

Maven Wrapper закрепляет Maven 3.9.9; вручную устанавливать Maven не требуется. При первом запуске нужны доступ к Maven Central и репозиторию PaperMC. JDK 21+ необходимо установить отдельно.

```bash
# Linux / macOS
./mvnw --batch-mode clean verify

# Windows
mvnw.cmd --batch-mode clean verify
```

Результат: `target/SmashEgg-4.0.0.jar`. Shade-плагин не используется: серверный API и Adventure предоставляет Paper, в JAR плагина библиотек нет.

JUnit / Mockito тесты покрывают шансы и границы, правила по мирам и мобам и их приоритет, оба режима фильтра, права, Creative, обе руки, расход и выбрасывание яйца, отменённые события, интерактивные блоки, подтверждение смены спавнера, разбор звуков и частиц, плейсхолдеры, MiniMessage-экранирование, статистику и её сохранение, валидацию и атомарность reload. GitHub Actions выполняет `clean verify` на Java 21 и 25 и публикует JAR и отчёты тестов.

Unit-тесты не заменяют запуск Minecraft. Перед установкой на рабочий сервер выполните [ручной чек-лист](docs/TESTING.md), особенно с плагинами защиты регионов.

## Структура

- `SmashEgg` — жизненный цикл, атомарная загрузка настроек и языка, отправка эффектов через Adventure, статистика.
- `EggListener` — игровые события, инвентарь, эффекты при поломке и неудаче.
- `PluginSettings` — неизменяемый проверенный снимок конфигурации, правила по мирам и мобам.
- `Rules` — базовые правила и их переопределения.
- `EggTypes` — распознавание материалов яиц и нормализация названий.
- `Sounds`, `Particles`, `Messages` — разбор эффектов из конфига.
- `Placeholders`, `ColorUtil` — подстановка значений и MiniMessage.
- `Stats` — счётчики и их файл.
- `CommandHandler` — команда, автодополнение, `/info` и `/stats`.
- `ConfigNodes`, `SectionFields` — разбор и валидация узлов конфига.

Что пока не реализовано и какие есть идеи развития — в [docs/ROADMAP.md](docs/ROADMAP.md). История версий — в [CHANGELOG.md](CHANGELOG.md).

Автор: **qweyns**. Java-пакет `org.karton.smashegg` сохранён для совместимости структуры проекта.
