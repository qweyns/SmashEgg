# SmashEgg 🥚 — v2.0 Global Overhaul

![Version](https://img.shields.io/badge/version-2.0.0-pink.svg)
![Java](https://img.shields.io/badge/java-17%2B-blue.svg)
![Platform](https://img.shields.io/badge/platform-spigot%20%7C%20paper%20%7C%20purpur-green.svg)

**SmashEgg** — это легкий и гибкий плагин, который добавляет механику "хрупкости" для яиц призыва. Теперь игрокам нужно полагаться на удачу не только при изменении спавнера, но и при обычном призыве мобов на землю!

---

## ✨ Что нового в v2.0
* **Раздельная логика:** Свои шансы для спавнеров и для обычного спавна на землю/стены.
* **Ground-Spawn Chance:** Новая механика — яйцо может разбиться прямо в руках, не призвав моба.
* **MiniMessage & HEX:** Полная поддержка современного форматирования текста. Забудьте про `&`, используйте градиенты и HEX-цвета.
* **Тотальная кастомизация:** В плагине больше нет хардкода. Все сообщения (даже логи консоли) и звуки вынесены в конфиг.
* **Поддержка 1.21.x:** В базу добавлены все новые мобы (Бриз, Боггед, Броненосец и др.).

---

## 🛠 Команды и Права

| Команда | Описание | Право (Permission) |
| :--- | :--- | :--- |
| `/smashegg reload` | Перезагрузка конфигурации | `smashegg.reload` |

> **Примечание:** Базовое право на использование плагина — `smashegg.use` (по умолчанию есть у всех).

---

## 📦 Установка

    Скачайте актуальный .jar файл из релизов.

    Положите его в папку plugins.

    Перезапустите сервер (рекомендуется удалить старый config.yml, если вы обновляетесь с v1.0).

## ⚙️ Конфигурация (config.yml)

Плагин поддерживает "живую" перезагрузку. После правок просто введите `/smashegg reload`.

```yaml
settings:
  # Настройки для спавнеров
  egg-break-on-spawner: true
  egg-break-chance: 30       # Шанс поломки (в %)

  # Настройки для обычного призыва (на землю)
  ground-spawn-chance: 70    # Шанс успеха (в %)

  # Черный список для спавнеров
  black-entities:
    - "ENDER_DRAGON"
    - "WITHER"
    - "WARDEN"

sounds:
  success: "ENTITY_PLAYER_LEVELUP"
  failure: "ENTITY_VILLAGER_NO"
  denied: "BLOCK_ANVIL_LAND"
  egg-break: "BLOCK_GLASS_BREAK"

  no-permission: "<#E43A96>▶ <#E43A96>У вас <#E43A96>нет <white>прав для этого."
